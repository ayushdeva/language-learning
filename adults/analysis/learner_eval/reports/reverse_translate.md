# Learner-profile eval: reverse_translate

Generated by `uv run python -m learner_eval.run`. SLAM's own split: each learner's exercises are train, then dev, then test (the last ~10%) in time order. Every learner is replayed in time order: predict P(wrong) for every token of the next exercise from the profile, then update the profile. Only test exercises are scored. Population statistics and model weights are fitted on the train split only.

## Baselines

| model | what it does |
|---|---|
| `random` | A uniformly random probability for every token. The floor: knows nothing, and is confidently wrong half the time. |
| `base_rate` | The overall error rate of this task type in the train split, for every token. The reference (skill = 0). |
| `learner_past_accuracy` | This learner's own error rate so far (all words), smoothed toward the base rate. Knows who, not what. |
| `word_difficulty` | How often other learners got this word wrong (train split). Same for every learner: knows what, not who. |
| `ability_x_difficulty` | Combine the two above on the log-odds scale: a weak learner on a hard word gets both penalties. Nothing is fitted. |
| `profile_lr` | Logistic regression on features read from the full profile: word difficulty, learner ability, how the learner did on this word / lemma / morphology before, and how long since they last saw the word. |

## Metrics

- **skill** (headline) = 1 - LogLoss(model) / LogLoss(base_rate). 0 = no better than knowing how hard the task is on average; 1 = perfect; negative = worse than that. Rewards both ranking and honest probabilities.
- **AUROC**: chance a random wrong token gets a higher prediction than a random right one, pooled over all test tokens (SLAM's official metric, same split: 2018 baseline ~0.77, best ~0.86, though those cover all formats).
- **AUROC within exercise**: AUROC over pairs of tokens from the same exercise (one wrong, one right). Same learner, same moment, so *who* is weak cancels out; measures whether the model knows *which* words this learner will miss. (Per-learner AUROC was dropped: a learner's past error rate is mechanically anti-correlated with their remaining answers, which unfairly penalises history-based features.)
- **F1@0.5**: SLAM's secondary metric. With error rates ~20%, most predictions stay below 0.5, so it is low for all models; kept only for comparability.
